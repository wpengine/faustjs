# Support Policy

Faust.js is in maintenance mode. There is no end-of-life date, and WP Engine continues to maintain the packages and plugin listed below.

For new headless WordPress projects, we recommend the [Headless WordPress Toolkit](https://github.com/wpengine/hwptoolkit). It provides guidance, examples, and minimal packages that work with any front-end framework.

## What we maintain

| Package                                                                | Status     |
| ---------------------------------------------------------------------- | ---------- |
| [`@faustwp/core`](packages/faustwp-core)                               | Maintained |
| [`@faustwp/cli`](packages/faustwp-cli)                                 | Maintained |
| [`@faustwp/blocks`](packages/blocks)                                   | Maintained |
| [Faust.js WordPress plugin](https://wordpress.org/plugins/faustwp/)    | Maintained |
| [`@faustwp/block-editor-utils`](packages/block-editor-utils)           | Deprecated |
| [`@faustwp/experimental-app-router`](packages/experimental-app-router) | Deprecated |

## What's in scope

- Security fixes. See [SECURITY.md](SECURITY.md) for how to report a vulnerability.
- Compatibility with supported versions of WordPress, WPGraphQL, Next.js, React, and Node.js.
- Fixes for critical bugs, such as crashes, data loss, or regressions from a recent release.
- Documentation corrections on [faustjs.org](https://faustjs.org).

## What's out of scope

- New features and new APIs.
- New example projects.
- Support for other front-end frameworks.

We close feature requests and feature pull requests with a pointer to the Headless WordPress Toolkit.
