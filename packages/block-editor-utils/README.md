> This package has been **deprecated**. It only supports React 18 and depends on `@wordpress/*` editor packages that pull in `showdown`, which has unpatched security advisories. For new projects, see the [Headless WordPress Toolkit](https://github.com/wpengine/hwptoolkit). You may continue to use this package though it will not receive any further bug fixes or security patches. If you need bug fixes or security updates we'd recommend copying the source code of this package directly into your project for use or use a tool such as [`patch-package`](https://www.npmjs.com/package/patch-package).
